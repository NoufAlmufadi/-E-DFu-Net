This repository contains the codes written and implemented for E-DFu-Net model for the binary classification of ischemia and the binary classification of infection
for the papers: 'E-DFu-Net: A Efficient Deep Convolutional Neural Network for Classifying Diabetic Foot Ulcers' by Nouf F. Almufadi, Haifa F. Alhasson, and Shuaa S. Alharbi'
and 'Classification of Diabetic Foot Ulcers From Images using a Machine Learning Approach'

* Please reference the papers or this repository when using these codes.
